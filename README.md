**Secure Bank System Transaction**
----------------------------------
A secure banking transaction management system developed using Spring Boot, Spring Security, JWT Authentication, MySQL, and JPA. The project provides secure account management, money transfer functionality, fraud detection, beneficiary management, and transaction monitoring.

**Features**
------------
Authentication & Security
-------------------------
User Registration
User Login
JWT Token Authentication
Protected APIs using Spring Security
Password Encryption using BCrypt

Account Management
-------------------
Create Bank Account
View Account Details
Account Freeze / Unfreeze
Account Status Tracking

Transaction Management
-----------------------
Secure Fund Transfer
Transaction History
Account Balance Validation
Daily Transfer Limit

Fraud Detection
----------------
Risk Analysis Engine
High-Risk Transaction Detection
Fraud Monitoring APIs
Automatic Account Freeze for Suspicious Activities

Beneficiary Management
-----------------------
Add Beneficiary
View Beneficiary List
Beneficiary-Based Transfers

----------------
